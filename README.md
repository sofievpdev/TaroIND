# Tarot Telegram Bot (English)

English Telegram bot for Tarot readings with ChatGPT and Telegram Stars payments.

## Features

- 🌟 One Card reading - quick answer from the Universe
- 🔮 Three Cards spread - Past → Present → Future
- 💖 Love Reading - 5 cards about your relationship
- 💞 Compatibility Reading - discover your connection with another
- ✨ Celtic Cross - deep 10-card analysis
- 🎁 Package deals with savings
- 💫 Free trial reading for new users
- 💰 Telegram Stars payment integration
- 📊 Admin statistics dashboard

## Tech Stack

- Node.js
- Telegraf (Telegram Bot Framework)
- OpenAI API (GPT-4o-mini)
- Supabase (PostgreSQL database)
- Telegram Stars payments
